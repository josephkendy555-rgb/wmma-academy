# WMMA Academy Haiti

**We Make Movies Academy Haiti** est une académie créative qui accompagne les jeunes Haïtiens dans le développement de leurs talents artistiques et numériques.

## Nos programmes

- Cinéma et réalisation
- Production musicale
- Design graphique
- Création de contenu

## Notre mission

Offrir aux jeunes un espace d’apprentissage pratique pour développer leurs compétences, exprimer leur créativité et transformer leurs idées en projets concrets.

## Technologies

- Next.js
- React
- TypeScript
- CSS

## Développement local

```bash
npm install
npm run dev
```

Ouvrez ensuite [http://localhost:3000](http://localhost:3000) dans votre navigateur.
